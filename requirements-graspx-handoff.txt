# yolo_seg + GraspGenX 성능개선 테스트용 — 전달용 최소 의존성 목록.
# 전체 ws 의존성은 워크스페이스 루트 requirements.txt 가 정본이다. 이 파일은 그 서브셋 +
# 이 테스트에만 필요한 컨테이너 의존성이다. 자세한 설정 절차는 README-graspx-handoff.md.
#
# ---------------------------------------------------------------------------
# [A] 호스트 (ROS 노드 실행 — grasp_bridge_node, capture_graspgenx_scene)
# ---------------------------------------------------------------------------
#   sudo apt install \
#     ros-humble-desktop \
#     python3-opencv python3-numpy python3-yaml \
#     ros-humble-cv-bridge ros-humble-tf2-ros \
#     ros-humble-realsense2-camera ros-humble-realsense2-description
#
# pip 로 opencv-python / numpy>=2 를 깔지 말 것 — cv_bridge 가 깨진다(둘 다 apt 로만).
# 호스트에는 pip 로 더 깔 게 없다 — grasp_bridge_node.py/capture_graspgenx_scene.py 는
# apt 패키지만으로 돈다(2026-08-09 import 실측 — trimesh/torch 는 [C]의 uv venv 안에서만 쓴다).
#
# ---------------------------------------------------------------------------
# [B] GraspGenX 워커 (grasp 계산 — 별도 GPU, uv 로 격리)
# ---------------------------------------------------------------------------
#   git clone https://github.com/NVlabs/GraspGenX.git && cd GraspGenX && uv sync
#
# torch·trimesh·numpy==1.26.4 등은 GraspGenX 자신의 pyproject.toml/uv.lock 이 정본이다.
# 여기 따로 안 적는다 — 두 곳에 버전을 적으면 반드시 어긋난다.
#
# ---------------------------------------------------------------------------
# [C] YOLO 세그 컨테이너 (yolo_seg_node — GPU, ultralytics)
# ---------------------------------------------------------------------------
# 호스트에 torch/ultralytics 를 넣지 말 것 — numpy 를 끌어올려 cv_bridge 를 깬다.
# 반드시 컨테이너(도커) 안에서만 pip install 한다. 이 랩탑(RTX 4060, driver 확인 필요)에서
# 검증된 조합 — 다른 GPU/드라이버면 torch 인덱스만 맞는 CUDA 빌드로 바꿀 것
# (예: driver 550.x 대엔 cu124, 560.x+ 는 cu130 — `nvidia-smi` 상단 CUDA Version 참고):
ultralytics==8.4.113
numpy==1.26.4
# torch 는 CUDA 빌드가 드라이버에 종속적이라 별도 인덱스로 설치한다. 예:
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
# 정확한 버전(torch 2.13.0+cu130)은 이 랩탑 한정 실측값이다 — 그대로 강제하지 말 것.
